A per-user data encryption key (DEK) protects content and derives the database key, exchanged securely and rotated over time.

## What this covers

- `DekKeyStore`, `SessionDekHolder`, `DatabaseKeyManager`; `DatabaseKeyTransition` / `DatabaseKeyTransitionDecision` KEK rotation.
- Remote wrapped-DEK exchange: `UserKeyApi` / `UserKeyApiClient`, `GetUserKeyResponse`.
- DEK-unavailable handling: `V2DekUnavailableScreen`.
