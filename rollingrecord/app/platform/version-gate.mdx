description: "The minimum-supported-version kill switch."

A version gate enforces the server's minimum-supported build floor and blocks under-floor clients.

## What this covers

- `AppVersionGate` enforcing the server min-supported floor; `AppVersionHeaderInterceptor` (`X-App-Version`) and `ClientTooOldInterceptor`.
- Kill-switch re-evaluation on Remote Config changes.
