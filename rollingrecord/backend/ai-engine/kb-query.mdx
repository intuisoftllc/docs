kb_query powers the conversational chat, metering one query per turn under a handler-owned round budget while the client owns the tool definitions.

## What this covers

- Handler-owned round-budget model: session tokens, max_rounds_exceeded, first-round-only ai_queries increment (continuation rounds free); kb-query-caps.ts.
- The client owns the 14 kb_query tool definitions (navigation IP is client-side); the server owns the behavioral system prompt (prompts/kb-query.ts, app-knowledge.ts).
