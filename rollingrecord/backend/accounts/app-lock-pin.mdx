set-user-pin writes a DEK-encrypted PIN verifier to user_crypto so App Lock syncs across devices while the server stays zero-knowledge.

## What this covers

- Writes/clears the DEK-encrypted PIN verifier (pin_verifier_ct/_iv) on user_crypto so App Lock syncs across devices; the server is zero-knowledge on the PIN; clearing requires an app_lock_pin_reset OTP ticket, setting does not.
