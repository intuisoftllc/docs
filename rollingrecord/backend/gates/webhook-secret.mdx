Server-to-server callers authenticate with a per-function shared secret rather than the service role key, following least privilege.

## What this covers

- webhook-secret.ts shared-secret Bearer auth (AuthMode.WebhookSecret); each server-to-server function uses a dedicated secret (REVENUECAT_WEBHOOK_SECRET, STORAGE_JANITOR_SECRET, EXTRACT_RUNNER_SECRET, ANALYTICS_INGEST_SECRET) rather than the service role key (least privilege).
