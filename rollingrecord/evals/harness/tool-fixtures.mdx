Canonical tool fixtures inject the real production tool definitions into `kb_query` cases so evals exercise the true tool surface.

## What this covers

- `evals/core/tool_fixtures.py` loads `evals/fixtures/kb_query_tools.json` — the REAL production tool set injected when a `kb_query` case omits its own `tools` (replaces the old 2-tool sandbox).
- The fixture is GENERATED by the Gradle `KbToolSpecSnapshotTest` (drift fails the build); the regenerate command is embedded in the error message.
- `validate_mock_tool_names` catches stale/typo'd `mock_tools` keys (e.g. leftover `searchContext`) against the canonical tool names.
