The harness tracks spend per run and diffs each result against a per-suite baseline to detect regressions.

## What this covers

- `CostLedger`/`AnthropicUsage` (`evals/core/cost.py`) splitting production vs judge spend, cache-token pricing, and where per-round session cost is recorded.
- Baseline diffing in `Runner._baseline_diff` (`suites/<suite>/baseline.json`): `new`/`unchanged`/`regression`/`fix`/`changed`; regressions always break the build.
- Flake handling: `is_flake` routes FAIL/UNCERTAIN to `cases_flaked`, excluded from exit-code and regression signal.
