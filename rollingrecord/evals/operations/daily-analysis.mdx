One analysis file per day records what was tried during eval iteration, so future sessions don't repeat the same thrash.

## What this covers

- The `CLAUDE.md` HARD RULE: one `evals/results/YYYY-MM-DD/analysis.md` per day, read at session start, appended after each meaningful iteration.
- Required structure (Context / Run log / Patterns observed / Open questions) and what it is explicitly NOT.
- Why it exists: eval iteration is high-cost and thrash-prone; the file is the anti-oscillation record.
